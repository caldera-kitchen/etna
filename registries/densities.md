# Ingredient densities

What a stated volume of a named ingredient weighs, so that tools can turn a volume into a
weight (or back) — and say so when they cannot. One row per ingredient. How to read, add and
source a row: [docs/densities.md](../docs/densities.md).

- **No row without a source.** A house value, a measurement, a package label, a definition, or
  a source the guide allows — never a number from memory.
- **A collection may keep its own `densities.md`** with a table of the same shape; its rows
  override these by name. This file is the default that ships with Etna.

House values are Vincent's.
